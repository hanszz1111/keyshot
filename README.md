# 形照 · AI 白模产品渲染器

把 3D 白模或产品图片变成产品展示候选图的本地工作台。面向 Windows 使用：Blender 负责从模型生成白模、深度和法线图；ComfyUI 负责 AI 出图；网页负责导入、选机位、CMF、任务和结果对比。

> 当前定位：个人设计探索与本地试用，不是几何精度或商业交付的保证。产品孔位、丝印、标识、透明件等关键细节必须对照原模型人工检查。

## 快速开始

1. 准备 Windows 上的 ComfyUI 便携版和 Blender 4.x。千问实例就绪时会作为默认生图入口；稳定模式 SDXL/ControlNet 仍可手动选择。
2. 克隆仓库后，按 [Windows 安装与启动](docs/Windows-快速开始.md) 核对安装路径与组件。
3. 双击根目录的 **`一键启动.bat`**，网页会自动打开；通常地址是 `http://127.0.0.1:8765/`。
4. 导入 3D 白模，选择「8 常用（含 3/4）」或需要的机位，选材质、配色和灯光，再点击生成。缺失或过期的结构图会先补齐；图片输入可直接进入图片改图模式。
5. 用 **`停止服务.bat`** 结束服务。只关启动窗口不一定会停止后台服务。

Windows 实机验收范围见 [功能与限制](docs/功能与限制.md)。这条分支的“自动补齐后出图”已通过 Mac 端代码自检，尚待 Windows 真实模型与 RTX 4060 Ti 8GB 端到端复验。

## 主要功能

| 功能 | 当前实现 |
|---|---|
| 模型导入 | BLEND、GLB、GLTF、OBJ、STL、FBX；STEP/STP 需 Blender STEPper 或 FreeCAD 回退；Rhino 3DM 需 `import_3dm` 扩展及文件内渲染网格。 |
| 机位与结构图 | 六视图、左右前 3/4 与特写；每机位归档白模、深度、法线。选好机位后可手动补齐，也可在生成前自动补齐。 |
| 出图模式 | 千问就绪时默认选中，可设置每视角候选数、质量步数和按白模比例换算的尺寸预算；八面图按候选系列先出主视图，其余机位同时参考各自白模与主视图外观。SDXL/ControlNet 保留为备选。 |
| 设计控制 | CMF 材质/纹理/工艺预设、布光与设计语言预设、参考图、按部位局部处理。 |
| 检查与留痕 | 3D 预览、白模/成图对比、任务列表、结果保存、参数卡与过程记录。 |

## 仓库结构

```text
web/       网页界面、本地服务和自检
scripts/   Windows 启停、Blender 结构图与辅助脚本
config/    工作流、预设和参数配置
docs/      用户指南、方案、验收记录与历史归档
AI/        双电脑协作的任务、结果、决策与复审
assets/    本地产品模型与输入图；不入 Git
outputs/   本地生成结果；不入 Git
```

根目录保留 `一键启动.bat` 和 `停止服务.bat` 作为唯一日常入口。`启动全部.bat` 是兼容旧习惯的同流程入口；`web/index.v17.html` 和 `web/index.classic.html` 不参与当前运行。

千问的双参考只能**增强**跨视角色彩、材质与设计语言一致性，不能保证八张图与 CAD 完全同形或所有隐藏面的 CMF 完全正确；该升级仍需 Windows 4060 Ti 8GB 实机验证速度、显存与成图。

## 安全与许可

本仓库**不包含**模型权重、ComfyUI、Blender、产品资产、客户资料或本地任务数据库。不要把这些内容、API 密钥或真实产品对照图提交到公开仓库。Qwen 模型权重的研究许可与本项目代码许可是两回事；本仓库目前**没有单独声明代码开源许可证**，不要仅凭 GitHub 可见性推断可再分发或商用。详见 [版本管理说明](GITHUB.md)。

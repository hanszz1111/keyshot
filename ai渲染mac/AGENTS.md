## 与 Windows 侧同步（GitHub）

本仓库：`https://github.com/hanszz1111/keyshot`（**public**，默认分支 `main`）。
Windows 侧与 Mac 侧是**同一个 GitHub 账号**，所以不需要加协作者——只要本机配好认证即可。

> **详细操作步骤见 `MAC-同步手册.md`**（首次配置、日常推拉、冲突处理都在里面）。

### 必须遵守的三条

1. **动手前先 `git pull`**。两端并行改同一个文件会冲突，先拉再改能避免九成麻烦。
2. **不要提交产品资产**。`.gitignore` 已排除 `assets/` / `outputs/` / `_隔离区/` /
   `config/tasks.db` / `config/card_*.json` 等。**新增大目录前先想一遍它该不该进仓库。**
3. **改完就推**，不要攒。这台机器上的改动只有推上去，Windows 侧才看得到。

### 两端分工（建议）

| 侧 | 擅长 | 说明 |
|---|---|---|
| Windows | 出图链路、Blender 出 pass、ComfyUI 实测 | 有 GPU（RTX 4060 Ti 8 GB）与全套模型 |
| Mac | 方案评审、文档、前端改动、AI 协作记录 | 通常无 NVIDIA GPU，跑不了 ComfyUI/CUDA 那套 |

**Mac 侧不要尝试跑出图链路**（需要 NVIDIA GPU + ComfyUI + 模型权重，都不在仓库里）。
Mac 侧适合改 `web/` 前端、`docs/`、`AI/` 这些纯文本部分。

### AI 协作目录 `AI/`

`AI/` 是给另一台电脑上的 GPT 做评审用的。**规则：**

- `MASTER_CONTEXT.md` / `DECISIONS.md` / `TASK.md` / `RESULT.md` 是**我方产出**，由 Windows 侧维护
- `REVIEW.md` 是**给 GPT 填的**，GPT 的意见写进这里
- GPT 读不到本机文件系统 → **所有判断依据必须内联写在文本里**，不能写"你去读某某文件"
- 每一轮结束后把结果推上来，两端都能看到

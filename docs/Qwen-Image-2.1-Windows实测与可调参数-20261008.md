# Qwen-Image-2.1：Windows 实测结论与可调参数

更新：2026-10-08。适用：RTX 4060 Ti 8GB、本项目千问图片编辑链路。**这是参数与运行结论，不是画质排名**；输出样张仍只在 Windows 本机，仓库没有人工逐图评分。

## 已有证据

- [本项目 Windows 部署实测](../AI/QWEN21-本地部署实测.md)：896 像素预算、八机位、35 步约 435 秒；同条件 50 步约 592 秒。18 张任务全部完成，但没有可复核的画质/结构评分。
- [本项目首轮 A/B](AB实验-千问提示词与CFG首轮记录-20261008.md)：768 预算、25 步、一个 SKU、正面和左前 3/4、两个种子。CFG=1 时，负面词有无对应的 4/4 组解码像素完全相同；CFG=1.5 时负面词开始影响结果，但正面耗时约 22.1→38.2 秒。像素变化**不等于**质量改善。
- [ComfyUI 官方 Qwen 2.1 编辑模板](https://github.com/Comfy-Org/workflow_templates/blob/main/templates/image_qwen_image_2_1_image_edit.json)使用 `TextEncodeQwenImage21`、KSampler；`resolution` 是按参考图比例换算的像素预算，CFG=1 时不使用负面词。默认 euler/simple、denoise 1.0 与本项目基线一致。[节点说明](https://github.com/Comfy-Org/docs/blob/main/built-in-nodes/TextEncodeQwenImage21.mdx)指出第一参考图决定编辑画幅；第二图只能辅助身份/CMF，不能锁住目标视角。
- [Qwen 官方示例](https://github.com/QwenLM/Qwen-Image-2.1)使用约 40 步与 guidance 1，不能推导“40 步必优于 25 步”，也不能推导 8GB 本机适合原生 2K。

## 这次开放的旋钮

| 界面参数 | 默认 | 可选范围 | 作用与边界 |
|---|---:|---|---|
| 出图尺寸 | 768 像素预算 | 640/768/896/992（原有） | 不是长边或固定宽高；双参考大尺寸在 8GB 上要先试单张。 |
| 渲染质量 | 25 步 | 15/25/35/50（原有） | 步数越高越慢；Windows 记录没有证明画质越高。 |
| 自定义步数 | 跟随质量档 | 8–50 的整数 | 用于固定其他条件时做单变量对照。 |
| 固定种子 | 自动 | 1–2147483500（原有） | 同输入/同参数时帮助重现；不同机位使用同种子不等于同一几何。 |
| CFG | 1.0 | 1.0 / 1.5 | 1.5 会让负面词参与且显著变慢；只作为实验档，不改默认。 |
| 主视图第二参考 | 开 | 开/关 | 关闭时各机位只看自己的第一参考，可诊断第二参考是否造成视角污染；关后不承诺八面外观关联。 |

采样器固定 `euler`、调度器固定 `simple`、降噪固定 `1.0`：它们虽然是工作流字段，但**没有**本项目同条件画质对照。尤其当前 `TextEncodeQwenImage21` 输出的潜变量不是通常的 img2img 原图潜变量，不能把调低 denoise 简单解释为“更保形”。本轮不开放这些高风险项，也不改变模型权重。

## Windows 下一轮最小验证

1. 先保持 768 / 25 步 / CFG 1 / 固定种子 43，仅比较“第二参考开/关”：正面、左前 3/4 各 1 张。检查 3/4 结构是否被主视图带偏；两种输入必须来自同一个 SKU 与 CMF 方案。
2. 固定第二参考与输入，再比较 25/35/40 步；记录每张 GPU 用时和结构、CMF、材质、背景、视觉主次五项 0–2 分。若结构或 CMF 为 0，直接淘汰，不因整体“高级感”而放行。
3. CFG 1 与 1.5 仅在相同输入/种子/步数下比较，至少覆盖正面和困难 3/4；若合格率没有提高，保留 1 作为默认。每次保存最终工作流参数与失败图的原因，不只看精选图。

**结论边界**：截至本轮，Windows 证明了参数能运行、耗时差异和 CFG=1 负面词无效；尚未证明哪一档画质最好，也尚未解决 AI 对 CAD 孔位、分模线、部件颜色的硬性保真。

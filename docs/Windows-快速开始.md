# Windows 安装与启动

返回 [项目首页](../README.md) · [文档索引](README.md)

## 1. 准备环境

推荐环境是 Windows、NVIDIA 显卡、Blender 4.x 和 ComfyUI 便携版。本项目当前使用 RTX 4060 Ti 8GB 做本地试验；其他显卡的速度和显存占用未在本仓库逐一验证。完整的模型权重与节点清单以实际工作流和 [Qwen 专项方案](Qwen-Image-2.1-Windows-部署与模型切换执行方案.md) 为准，不随仓库下载。

| 组件 | 默认位置 / 用途 | 不在默认位置时 |
|---|---|---|
| 稳定模式 ComfyUI | `F:\AI-Renderer\packs\ComfyUI_windows_portable`，默认端口 8188 | 设置 `AI_RENDER_COMFY_ROOT` 为便携版根目录 |
| Blender | 生成白模、深度、法线和 3D 预览缓存 | 设置 `BLENDER_EXE` 为 `blender.exe` 完整路径 |
| Qwen 独立 ComfyUI（可选） | `F:\AI-Renderer\experiments\Qwen21\ComfyUI_windows_portable`，默认端口 8190 | 设置 `AI_RENDER_QWEN_ROOT`；不使用时设 `AI_RENDER_NO_QWEN=1` |
| STEP/STP（可选） | Blender STEPper 插件；缺失时使用 FreeCAD 回退 | FreeCAD 回退设置 `FREECAD_CMD` |
| Rhino 3DM（可选） | Blender `import_3dm` 扩展 | 纯 NURBS/曲面文件先在 Rhino 中生成渲染网格或导出 GLB/OBJ |

ComfyUI 便携版需要有 `python_embeded\python.exe`。没有它时网页可能仍可用已安装的 Python 3.11+ 启动，但不能因此视为本地出图链路已就绪。`.env.example` 是变量清单；启动脚本读取的是**系统环境变量**，不要以为只复制成 `.env` 就会自动生效。

稳定模式需安装工作流使用的 SDXL 底模、ControlNet 和对应节点。参考图的图像条件需要 IPAdapter；未装时界面会说明只把参考图配色转成文字条件。模型文件不在本仓库中。

## 2. 一键启动

1. 克隆或下载仓库到本机。路径尽量简短，避免放在受同步软件持续占用的目录。
2. 确认上表所需组件存在，尤其是 ComfyUI 与 Blender。
3. 双击根目录 `一键启动.bat`。脚本会复用属于本项目的现有服务，按需启动网页、稳定模式和可选的千问实例。
4. 打开脚本显示的 **Web UI** 地址。通常是 `http://127.0.0.1:8765/`；若被占用，会在 8765–8785 中选择可用端口。

脚本默认给 ComfyUI 使用 `--lowvram`。正常情况下，Windows 计划任务会保持服务运行；若计划任务不可用，脚本回退为普通进程。**关闭启动窗口不等于停止服务**。结束时双击根目录 `停止服务.bat`。

8GB 显卡上不要让稳定模式、千问和 Blender 同时执行重任务。千问路径不存在时会自动跳过，不影响稳定模式；只想用稳定模式时可设 `AI_RENDER_NO_QWEN=1`。

## 3. 首次验证

1. 网页能打开，服务状态能读到；若渲染服务仍在加载，稍等后点“刷新状态”。
2. 导入一个不含敏感信息的测试模型；在预览中检查方向与主体是否完整。
3. 先选“仅预览视角”补一组结构图，确认白模、深度和法线可见。
4. 再选“8 常用（含 3/4）”执行补图或生成，逐机位核对左右 3/4，不能把“任务完成”当作“画面正确”。
5. 做一次结果对比：检查轮廓、孔位、开口、文字和材料区域。

开发者可在仓库根目录运行 `python web/selftest.py` 做不依赖 GPU 的代码与本地接口自检。**自检通过不代表 Windows 模型导入、显卡出图或画质验收通过**。

## 4. 常见问题

| 现象 | 优先检查 |
|---|---|
| 找不到 ComfyUI | `AI_RENDER_COMFY_ROOT` 是否指向便携版根目录，内有 `python_embeded\python.exe`。 |
| 网页打开但渲染服务离线 | 等待模型加载；检查对应 ComfyUI 窗口或服务日志；不要误连另一项目的 8188/8190。 |
| 白模或深度图缺失、过期 | 选中正确产品和机位，点“补齐所选视角结构图”；自动补齐失败时查看页面给出的具体机位原因。 |
| STEP/STP 不显示 | 检查 STEPper 是否启用；或检查 FreeCAD 回退及 `FREECAD_CMD`。 |
| 3DM 不显示 | 检查 `import_3dm` 扩展；纯曲面文件尝试先导出带渲染网格的 GLB/OBJ。 |
| 3/4 视角不正确 | 分别核对 3D 预览、白模、深度和最终成图；只有同机位结构图齐全，不代表 AI 保形。 |
| 网页没有自动打开 | 使用启动窗口显示的 Web UI 地址，不要固定假设端口一定是 8765。 |

更多操作见 [使用指南](使用指南.md)，完整试验与待办见 [过程文档](../00-AI白模渲染器-过程文档.md)。

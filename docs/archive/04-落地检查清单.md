# 落地检查清单

> 用法：每个阶段逐项打勾，**任何一项没过就不要进入下一阶段**。
> 这份清单的目的是防止"看起来跑通了但一上量就崩"。

---

## P0 · 可行性验证（3–5 天）

### 环境

- [ ] Python **3.11**（不要用 3.13，AI 生态兼容性差）
- [ ] CUDA 12.4/12.8 + 对应版本 PyTorch，`python -c "import torch; print(torch.cuda.is_available())"` 返回 True
- [ ] ComfyUI 源码部署（**不要用整合包**，流水线要改节点）
- [ ] ComfyUI-Manager 已装并能正常拉插件
- [ ] 插件 4 件套：`comfyui_controlnet_aux` / `ComfyUI-IC-Light` / `ComfyUI_IPAdapter_plus` / `ComfyUI_AdvancedRefluxControl`
- [ ] 底模已下（FLUX.1-dev fp8 或 SDXL 系），能正常出图
- [ ] ControlNet depth / normal 模型已下并能在节点里选中
- [ ] FLUX.1-Redux-dev + clip_vision 已下（若走 FLUX 路线）
- [ ] KeyShot 版本 ≥ 9.3 且为 **Pro**（headless scripting 是 Pro 功能）

### 素材

- [ ] 选定 1 个 SKU（建议从结构简单、无透明件的产品开始，别拿透明视窗款练手）
- [ ] 白模已就绪（`.ksp` 或 `.glb`）
- [ ] KeyShot 能导出 **2048 长边**的 beauty 图
- [ ] Blender 能导入同一模型，且**相机参数与 KeyShot 一致**

### 核心验证（最关键）

- [ ] 出了 depth 和 normal 两张 pass
- [ ] **Pass 与 beauty 像素级对齐**（叠图看边缘，偏移 < 2px）
- [ ] 只开 Depth ControlNet，prompt 里**故意不写任何形状描述**
- [ ] 出图结果：**轮廓、厚度、按键位置一眼可辨认为同一产品**

> ⛔ **这一条不过，整个方案暂停。** 说明 pass 或相机参数有问题，跟调 prompt 无关。
> 常见原因：法线空间不一致、depth 归一化方向反了、相机焦距/机位对不上、模型导入后缩放不一致。

- [ ] 用 `align_check.py` 跑一次，IoU ≥ 0.90

### P0 交付物

- [ ] 1 个 SKU × 3 视角 × 各 2 张 的对比图（白模 / 成图 并排）
- [ ] 记录：base 参数下的 depth 权重、耗时、失败模式
- [ ] 一页复盘：**形准率大概多少？哪些部位最容易崩？**

## P1 · 单机流水线（1–2 周）

### 参数化

- [ ] 参数卡 schema 定稿（`config/param_card.schema.json`）
- [ ] 至少 3 个类目的参数卡预设（激光水平仪 / 气体检测仪 / 其他）
- [ ] 提示词模板库覆盖：材质词表、光照词表、背景词表、通用负向词
- [ ] 负向词里**包含** `text, numbers, logo, markings`（防 AI 瞎猜丝印）
- [ ] 自然语言 → 参数卡的 LLM 解析跑通，人工复核一遍准确率

### 参考图机制

- [ ] 参考图库至少积累 10 张（材质参考 5 / 打光参考 3 / 构图参考 2）
- [ ] L1 风格轻参考验证（IP-Adapter 0.4–0.6）
- [ ] L2 材质参考验证（Redux + 蒙版限定部位）—— **这条是"仿照渲染"的核心菜**
- [ ] L3 整体仿照验证（Redux 高权重 + 图生图 denoise 0.5–0.7）
- [ ] 确认 Redux 的正方形限制已处理（center crop / keep aspect ratio / autocrop with mask）

### 自动化

- [ ] ComfyUI 以 `--listen 127.0.0.1 --port 8188 --output <dir>` 常驻启动
- [ ] 工作流导出为 **API format**（Dev Mode → Save (API format)），节点 ID 是数字
- [ ] `comfy_batch.py` 能提交任务并轮询到结果
- [ ] SQLite 任务表建好，`running` 状态在重启后能自动重置（断点续跑）
- [ ] 超时保护生效（默认 600s）
- [ ] 失败重试 ≤ 2 次，超限写 `failed` 并记录原因
- [ ] 命名规范落地：`{类目}_{SKU}_{视角}_{风格}_{版本}_{语言}.png`

### 后处理

- [ ] BiRefNet 抠图接入，透明件边缘效果可接受
- [ ] Real-ESRGAN 超分接入，2x / 4x 都能跑
- [ ] **LOGO / 刻度回贴脚本跑通**（这一步别省）
- [ ] 同 SKU 多图色彩统一（LUT 或直方图匹配）

### 验收

- [ ] 喂 20 个 SKU 的参数卡，**无人值守跑完一整批**
- [ ] **成品率 ≥ 70%**（人眼判断"可直接用，或只需轻微修"）
- [ ] 失败原因分布已统计（形不准 / 材质崩 / 透明件 / 其他）
- [ ] 单张总耗时（含后处理）≤ 60s

## 通用 QC 标准（每批必查）

### 结构

- [ ] 与白模叠图 diff，轮廓偏移在阈值内
- [ ] 按键 / 旋钮 / 接口 / 刻度盘**数量和位置**正确
- [ ] 厚度关系正确（不能把圆柱拉成方的，不能丢倒角）
- [ ] 无多余部件、无融合畸变

### 材质

- [ ] 金属件有合理的高光走向，不是"画上去的反光"
- [ ] 磨砂件的颗粒感合理，不是均匀噪点
- [ ] 透明件有折射和边缘高光，不是半透明色块
- [ ] 无"背景颜色渗到产品上"

### 合规（重点）

- [ ] **生成的图与实物照片对比，无结构性差异**
- [ ] 量程 / 精度 / 认证标识 / 型号 **禁止由 AI 生成**，必须原图叠加
- [ ] 无 AI 幻觉出的功能部件（实物没有的东西不能出现）
- [ ] 无异国文字乱码
- [ ] 图片中不出现他人品牌 / 商标

### 交付

- [ ] 分辨率 / 色彩模式 / 命名符合规范
- [ ] 文件已按类目 / SKU 归档
- [ ] 版本号递增，旧版未覆盖

## 常见失败模式速查

| 症状 | 最可能的原因 | 第一个该动的地方 |
|---|---|---|
| 形不准、整体"胖了/瘦了" | Camera 参数不一致 或 Depth 权重低 | 先查 pass 对齐，再提 depth 权重 |
| 局部结构错乱（按键多了少了） | Depth/Normal 权重平衡问题 | 提 normal 到 0.45+，看是否锁定 |
| 金属像塑料 | Normal 权重过高、Normal 空间错 | 降 normal，**核对相机空间法线** |
| 透明件变成灰块 | AI 对透射材质能力不足 | 别硬刚，改走"真渲染合成" |
| 参考图完全不起作用 | Redux 权重太低 | `downsampling_factor` 3 → 1 |
| 参考图把形状带歪了 | Redux 权重太高 或没做蒙版限定 | 降权重，或改 L2 + 蒙版 |
| 同款多图风格漂 | seed / 参考图不固定 | 固定 seed 基数 + 同一参考图 |
| 批次跑到一半整体变差 | 某张 pass 生成失败，串了数据 | 检查 pass 目录完整性，加文件校验 |
| 队列静默卡住 | 节点 CUDA 报错未通过 API 返回 | 看 ComfyUI 终端，必设 timeout |

## 为什么归档

项目在早期有两条并行推进线：Windows 侧（本机，有 GPU，出图链路）与 Mac 侧（无 NVIDIA GPU，偏方案/文档/前端）。
Mac 侧曾独立维护一份「方案与过程记录」，与 Windows 主文档大量重复。

SSOT（`00-AI白模渲染器-过程文档.md`）第五章已明确：

> 新文档若与本文件重复，应整合到这里或 README，**不再扩展多个并行总纲**。

故本目录两份文档**停止维护、只作追溯**。

关键参数 depth / normal
调参顺序不能平行：只开 Depth（0.60 起）→ 加 Normal（0.35 起）→ 加参考图（低权重）→ 最后才调 prompt。 Normal 超过 0.5 画面会发"塑料感"。
附属件 trim 可选
透明件 window 可选
AI 对透射材质能力不足。带透明件的产品建议透明区域用 KeyShot 真渲染后合成。
相机与背景色 必须与出 pass 一致
参考图仿照 可选 · 三档强度必选
参数卡 JSON 双向同步

        投放区是「路径」这件事的唯一入口。规则很简单：

        ① 白模源文件（.ksp / .blend / .glb / .fbx / .stp …）丢进 assets/白模/；

        ② 白模渲染出的 pass 图丢进 assets/passes/<SKU>/<机位>/，通道名用 clay / depth / normal；

        ③ 文件名或目录名里带 SKU、机位、通道就会自动归位。直接拖文件夹也行，中英文命名都认。

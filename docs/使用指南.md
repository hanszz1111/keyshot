# 使用指南

## 从 3D 白模生成产品图

1. 在“选择产品”导入模型。可直接处理 BLEND、GLB、GLTF、OBJ、STL、FBX；STEP/STP 与 3DM 需要 [Windows 快速开始](Windows-快速开始.md) 中列出的转换能力。`.rhi`、`.rhp`、`.yak` 和 `.3dmbak` 不是可直接导入的模型。
2. 等待白模预览；用 3D 预览旋转模型确认方向、比例和部件是否可见。预览仅用于检查，**不能代替最终机位结构图**。
3. 在“出图视角”选机位。可用“仅预览视角”“4 标准”“8 常用（含左右前 3/4）”或逐项勾选。六视图快捷按钮不包含左右 3/4。
4. 选择稳定或千问引擎，设定材质、纹理、工艺（CMF）、配色、设计语言和灯光。参考图片可辅助配色/影调；界面会说明是否有图像条件组件参与。
5. 点击生成。缺失或过期的机位会先顺序补齐整组白模、深度和法线；补图失败会停止本次出图并给出原因。也可以提前点击“补齐所选视角结构图”单独检查。
6. 在任务与结果区看成图，再用白模/成图对比功能检查轮廓、部件位置和细节。

两套引擎的“每视角候选数”都可选 1、2、4、15、30、50；总任务数 = 机位数 × 每机位候选数，单批上限为 200（例如八面 × 30 张会超限，需分批）。任务逐张处理，浏览器关闭后可在任务列表继续待办，**不等于后端会自行完成所有未执行任务**。千问顺序执行，每个候选系列先生成主视图，其余机位以各自白模为第一参考、同系列主视图为第二参考；主视图失败时该系列其余机位不会独立乱出。

结果区会把同一候选系列的多个机位放在一起，方便逐面核对。如果主视图超时仍在生成，其余机位保留为待运行；主视图完成后可从任务列表继续，而不是放弃关联参考直接出图。

### 给不同部位分别指定材质

1. 先设“主体材质”和“主体颜色”，作为未单独指定部件的默认外观。
2. 在“部位材质”点“到 3D 中选部件”，在模型上点击前壳、握持区等网格；填写易懂的部位名，选择材质和颜色，再点“保存到整机方案”。多个网格可填同一个部位名，以便归为一类。点“恢复主体材质”只移除当前部件的覆盖。
3. 每个机位需要先有有效结构图和对象 ID，才能把选中的网格映射到其他视角。缺图或模型更新时，生成前会明确阻断；源模型换了后，页面可确认备份旧方案并重新建立。旧的按机位局部编辑记录不会自动变成新方案。
4. 方案被记录到整批任务中。千问出图前会从当前机位白模和对象 ID 生成一张确定性**配色引导图**：例如前壳深灰、握持区黑色，作为当前机位第一参考；同候选系列主视图仍是第二参考。稳定模式也会收到部位材质说明，但仍要逐张核对。

配色引导图固定的是“哪块网格用哪种颜色”的参考分区，**不是**真实 PBR 胶皮纹理或金属反射成品。千问/SDXL 仍可能改动边界、孔位和表面细节；透明件、镜面镀铬等“仅真渲染”预设不能作为 AI 批次的精确材质承诺。配色图生成需要运行网页后端的 Python 环境已有 `numpy` 与 `Pillow`，缺少时会在提交任务时报明原因。生成图与方案留在本机，不自动上传 GitHub。

### 出图尺寸与质量

稳定模式默认“跟随结构图”，使结果与结构图保持相同宽高比。自定义尺寸若改变宽高比，产品可能被拉伸。质量档位是草稿 8 步、标准 12 步、精细 20 步、最高 32 步；当前 Lightning 底模超过约 20 步收益可能递减。旧实测曾在 RTX 4060 Ti 8GB 上跑通较大尺寸，但同时运行其他程序或换模型后显存余量不同，不把旧数值当作通用保证。

千问的尺寸是**按第一张白模原比例换算的像素预算**，可选 640、768、896、992，不是强行指定宽×高；8GB 显卡建议先用 768。质量档位是 15、25、35、50 步，标准 25 步为原工作流基线；提高步数通常增加耗时，不保证一致性一定更好。每个候选系列共享相同 CMF/布光文字设定和种子，但第二参考仍属于生成模型的软约束，务必逐图检查颜色、材料分区与孔位。

### 模型格式说明

- STEP/STP：优先用 Blender STEPper；缺失时可走 FreeCAD 缓存网格回退。原文件不因转换被修改。
- Rhino 3DM：需要 Blender `import_3dm`；扩展主要读取渲染网格，纯曲面文件需先准备网格或导出 GLB/OBJ。
- KSP、C4D、MAX：先从对应软件导出 GLB/OBJ 等支持格式。
- 上传会检查扩展名和文件内容；改后缀或损坏文件会被拒绝。

## 直接用产品图片改图

1. 切到“产品图片”，上传 PNG、JPG 或 WEBP 产品照片/现有渲染图。原图与“参考图”入口不同，不要放错。
2. 描述要改变的材质、颜色、灯光或背景，按需要上传风格参考图。
3. 调整改动幅度和候选数，再生成。此模式不需要白模或深度图，也**不会凭单张图片自动得到真实的其他机位**。输出按产品编号保存到 `outputs/<产品编号>/photo/`。

稳定模式的图片改图使用图像输入与 Canny 边缘约束。默认改动幅度 85% 是试验参数，**不是保形保证**；低于 55% 会被拒绝。白模/灰模截图会触发用于材质化的提示词，但自动识别并非绝对准确。

## 看图与验收

预览区可查看白模、3D 自由旋转、深度、成图与对比。对比档把同机位白模与成图放在一起；宽高比不一致时会并排显示，不能按像素重合判断。3D 预览支持旋转、缩放和机位快捷切换，但网页相机与 Blender 正式结构图的像素构图不保证完全相同。

逐张检查：整体轮廓、左右 3/4 是否真的显示目标面、孔位/开口/按钮数量、材料边界、透明件、丝印/LOGO/刻度。AI 可能凭空增加格栅、孔点或纹理。对结构与标识精度敏感的部分，应使用确定性渲染或后期回贴，不能只看“任务成功”。

素材与结果留在本机 `assets/`、`outputs/`，默认不会上传 GitHub。功能边界与待验证项见 [功能与限制](功能与限制.md)。

# 保留千问 INT8：工业材质与八视角优化方案

> 2026-10-10；用户已明确保留千问 INT8。依据 `main@8cfc998` 的代码、Windows 结果及后续更正。本文件是待实施设计；主模型和文本编码器均保持当前 INT8，不把新模型下载作为优化的前置。配套底层接口和数据格式见[架构报告](工业材质增强-底层架构与Windows实施报告-20261010.md)。

## 1. 固定的基线和目标

| 项目 | 本轮决策 |
|---|---|
| 主模型 | `qwen_image_2.1_int8_convrot.safetensors`，继续使用 |
| 文本编码器 | `qwen3vl_8b_int8_convrot.safetensors`，继续使用 |
| VAE | `qwen_image_2.1_vae_bf16.safetensors`，保持现有版本 |
| 基准采样 | 25 步、CFG 1、Euler/simple、现有参考图尺寸预算；先固定，不能和材质实验同时改 |
| 核心目标 | 材料像实物、光影有立体感、部件材质归属正确、八个视角是同一件产品 |
| 非优先项 | 更高画幅、过度锐化、极低噪点、风格 LoRA 堆叠 |

后续修改先在实验工作流中完成。模型权重文件名、内容 SHA-256、配置和实际 API 请求都写入事实卡，避免界面写 INT8 而实际加载其他版本。现有模型卡里的模式与参数不能直接套用到另一个底模。

## 2. 纠正实验认识，统一依据

- 最新 Windows 更正证明 32 个模型文件内容相同，指定部件真实可见；此前“模型版本错配/全部不可见/主要改了背景”的判断不再作为开发前提。参见[16 位读取更正](更正记录-PIL位深误导导致的两处错误结论-20261010.md)。
- 设计语言提示词确实能作用于指定部件，值得继续测试；像素变化更大不等于材质更准确。跨视角明暗变化符合光学规律，不能仅用“变亮比例不同”判不一致。
- 程序纹理已接入 Blender，但只验证了有限样本。当前 Git 默认工作流没有 CPU KV cache 节点；“约40%提速”是特定实验结果，接入与复测通过前不能写成生产收益。
- 所有 ID 归因必须完整读取 16 位数据；普通 Pillow 灰度转换不能用来读这类 16 位 RGBA 部件图。先以已知 ID 的合成图验证解码，再分析产品。

## 3. 推荐的最终流程

```text
原模型 + 部件材质方案 + 真实PBR贴图 + 固定灯光
                       ↓
冻结场景契约 → Blender 同场景八视角底图 / 深度 / ID
                       ↓
千问 INT8：以当前机位底图为主，有限度增强表面与光影
                       ↓
局部合成与结构检查 → 同系列八图对照 → 合格发布 / 回退底图
```

角色分工：Blender 决定几何、材质位置、纹理方向和可解释反射；千问提供摄影式润色。每一面必须有自己的同机位底图，不能拿正面图让模型猜背面。若采用同产品另一面作第二参考，仅提供身份/材质参考，不替换当前相机。

## 4. 优化包 A：真实材质底图（优先实施）

**修改入口：**`config/cmf_presets.json`、`scripts/blender_pass.py`、`web/server.py::product_base_spec()`；外部材料包按架构报告 schema 接入。

1. 先建立六个可靠材料：细砂 ABS、高光塑料、哑光 TPE、喷砂铝、直线拉丝铝、抛光钢。每个材料固定颜色、粗糙度、金属度、微法线强度、实际纹理尺寸和方向，材质球与产品共用着色逻辑。
2. 支持用户材料包中的颜色/法线/粗糙度/金属度图；标量缺图回退，不从照片亮度猜金属度。对塑料/橡胶保留明确的非金属属性。
3. CAD 单位与纹理物理尺寸绑定；多视角复用同一映射。拉丝轴与各向异性切线对齐，环向拉丝另建预设，不能统一沿 X 轴。
4. 新增中性检验、柔光棚拍、金属反光卡三档灯光；主光形成体积，弱补光保留暗部，反光卡表现倒角；地面阴影分层，仰视不得被地面挡住。
5. `scene_id` 纳入材质包 revision、着色器源码哈希、灯光/HDRI 哈希、模型/相机/单位。改材质代码必须让旧底图缓存失效；八面混签名不得标完成。

**验收：**同一产品正面/3⁄4/仰视切换时，纹理不游走、颜色归属不互换、分模线不消失；旧底图可比较和回退。先做确定性 PBR 对照，再启动千问。

## 5. 优化包 B：千问输入和提示词

**修改入口：**`prepare_qwen_prompt()`、`validate_cmf_task()`、配色引导与现有 Qwen 工作流构建路径。共用一份部件材质数据生成底图与提示词，避免前端手写一套、后端拼接另一套。

提示词按四段生成：当前机位编辑任务 → 可见部件的材质/工艺 → 目标布光 → 简短保形要求。默认 CFG=1 的必要约束放正向指令；不继续通过增加负面词长度期待收益。

示例：

> 精修第一张图中当前视角的产品。沿用底图的材质分区和颜色：外壳是细砂纹 ABS，握把是低反光 TPE，装饰环是沿环向拉丝的阳极铝。表现三种材料不同的高光宽度和表面细节，使用柔光棚拍与自然接触阴影。保持轮廓、孔位、按钮、分模线、部件数和已有文字的位置，只改善表面表现与光照。

实施顺序：①只替换为真实 PBR 输入；②固定输入后比较现有提示与上例写法；③再独立比较单参考与第二参考。每次固定种子/尺寸/步数/权重，不把多项变化归因给一个参数。

局部编辑作为独立子功能开发：由 ID 生成目标选区，裁切时保留上下文，千问输出仅在允许区域合成；边缘保护带和掩膜外逐像素不变作为验收条件。**当前全图编辑链不能因添加一段提示就标为支持掩膜编辑**；需实现完整裁切/合成后再开放 UI。

## 6. 优化包 C：8GB 下的性能与任务可靠性

1. 保留 INT8 主模型和编码器，材质生成/Blender GPU/Qwen 共用排他调度；不同时常驻多个大模型。开始一组任务时冻结配置，失败后可从同签名未完成机位继续。
2. CPU KV cache 单独试验：核验本机节点支持，使用现有 `scripts/qwen_ab_experiment.py` 的 cache 对照，比较无 cache 与 CPU cache；记录实际工作流、像素哈希、单/双参考耗时和峰值显存。复测通过再创建生产开关与回退配置，不预先承诺40%提升。
3. 首张展示实际已用时间；获得真实采样回调后才显示单张采样百分比。整组进度用已完成机位/候选数，预计剩余时间取同模型/尺寸/参考数的历史中位数，明确“预计”。
4. 图片点击打开原尺寸大图，支持底图/结果并排及同一部件局部放大；让用户看到材质改了哪里，不依赖压缩缩略图判断。

## 7. 可选增强模型何时加入

StableMaterials 仅负责生成可复用 PBR 材料，不替换千问主引擎。先完成 A/B 两包，再根据缺失材料逐项试单张512、标准与LCM分开记录；8GB未实测前标实验。Chord、IC-Light、Qwen Union 后续各开独立实验，不同时安装叠加。模型来源与环境隔离见[架构报告](工业材质增强-底层架构与Windows实施报告-20261010.md)。

## 8. 执行顺序、测试数量与准入

| 顺序 | 交付 | 验收 |
|---|---|---|
| 1 | 16位读取基线 + 现有权重/输入冻结 | ID合成夹具与Blender读取一致；配置实际使用INT8 |
| 2 | 材质包接入 + 六材料 + 缓存签名 | 材料变化产生新路径，旧图不混入；材质球/产品一致 |
| 3 | 三档布光 + 同场景八面 | 正俯仰/3⁄4正确；边界/纹理方向稳定，合理高光变化允许 |
| 4 | PBR输入/提示词/参考图逐项A/B | 结构硬错误不增加，目标部件的材质相似度改善 |
| 5 | CPU cache隔离复测 + UI比较 | 复测画面无回退且确有性能收益才启用 |
| 6 | 局部合成与可选生成材料 | 掩膜外不变、边界连续、跨八面不串材质 |

首轮：3 SKU × 3机位 × 2种子 × 2臂 = 36张千问结果；输入底图、提示词各自单独一轮。优胜方案扩展为3 SKU × 8机位 × 2种子 × 2臂 = 96张。确定性 Blender 底图无需重复换 AI 种子。

评估以部件为单位：轮廓/孔/接缝硬错误、材料与参考的相似度、纹理尺度与方向、反光/立体感、八面身份一致性。两人盲评0–2分，预先固定准入标准：无新增结构硬错误、跨视角CMF不下降、材质与立体感平均分提高才推广。MAE只作输出变化诊断，变亮面积须按目标部件可见面积归一化，不能当作质量分。没有双人/原图证据时结论标“待验证”。

每个提交附代码版本、工作流/材料/模型哈希、输入输出、耗时显存、成功失败统计、结论与回退入口；实际测试写入对应 `AI/RESULT` 轮次，修改登记根过程文档。此方案接受并固定千问INT8基线；新材质与新流程的效果须按以上门槛逐项验收。

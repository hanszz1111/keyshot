# 多部位材质组合与选区渲染 · 实施大纲

> 状态：设计提案，尚未实现或完成 Windows 实机验收。示例目标：前壳细砂纹塑料、握持区哑光 TPE 包胶、按键缎面金属；八面图视角变化时，同一物理部位不换材质、不串色。

## 1. 当前能力与真正缺口

当前已有统一 CMF 预设库（含塑料、橡胶、金属等）、3D 点选部件、按 `SKU + 机位 + 部件号` 保存材质、近似 3D 预览，以及“选一个部件→同机位掩膜→局部重绘→掩膜外确定性合成”的链路。**这不等于整机多材质已经可一键稳定出图**：常规整机与千问多视角任务在 `web/app.js` 的 `buildPayload()` 中仍以一个主体材质组提示词；部件分配表没有作为整机方案注入渲染输入。按机位保存的数字部件号也不能天然证明它是其他机位的同一物理部位。千问使用图片参考时，提示词对材质归属的控制是软约束，不保证边界和八面一致。

## 2. 用户操作设计

主页面保留简单路径，不让用户写长提示词：

1. 选模型后进入“部位与材质”。3D 模型上可点选部件，也可在当前白模视图上点击对象 ID 区域。选中区高亮，旁边显示“这是哪一块、目前是什么材质、哪些视角可见”。
2. 把多个网格合成一个**语义部位**，例如“前壳”“握持包胶”“按键”。用户可重命名、增删、拆分，不能仅凭导入文件中的 `物体.001` 自动推断语义。默认整机主体材质，其他部位覆盖。
3. 对每个部位分别选择 `材料 + 颜色 + 表面纹理/方向 + 工艺`；例如“前壳→细砂纹 ABS，#373D42”“握持区→细颗粒 TPE，#202326”。可保存“CMF 方案 A/B”，一键切换，并显示未指定部位列表。
4. 页面上有两种明确不同的出图按钮：**整机按方案渲染**（同时应用所有部位材质）和**仅修改选中部位**（以已有成图为底图，只更新选区）。局部模式要先预览掩膜，再执行，不应让用户误以为白模局部更新后整机已经上材质。
5. 高级选区允许“加选/减选部件”与 2D 画笔修边；画笔仅针对当前视角的图片，不自动变成 3D 选区。若希望八面一致，必须回到 3D 语义部位或对每个机位分别确认。

建议最简界面：

```text
部位与材质                         [保存为方案 A]
整机默认  ─ 细砂纹 ABS   深灰        [更换]
前壳      ─ 细砂纹 ABS   深灰        [定位] [更换]
握持区    ─ 哑光 TPE     炭黑        [定位] [更换]
按键      ─ 缎面金属     枪灰        [定位] [更换]
未分配 2 个部件（沿用整机默认）
[预览材质分区]  [整机按方案渲染]  [仅修改选中部位]
```

## 3. 数据与渲染方案

### P0：稳定的“一个产品、一套分配”

- 建立 `cmf_scheme`：`sku`、模型/几何指纹、方案版本、默认材质、部位分组、每组预设 ID、颜色与纹理覆盖、创建时间。分组成员优先绑定源网格稳定标识或几何映射；现有 `partId` 仅作**该机位掩膜 ID**，不能当跨机位主键。
- 每个视角生成时，从同一方案投影出该机位可见部件与掩膜，记录 `scheme_id + scheme_version + model_fingerprint + view + mask_hash`。模型重新导入、几何或 pass 更新后标记方案“需重新映射”，不默默沿用旧数字 ID。
- 提交前给出材质分区预览，检查掩膜非空、重叠和遗漏；一个像素不能同时归属两个互斥部位。相邻包胶/塑料边界先按真实网格或对象 ID 精准分割，笔刷只作为视角级修补。
- 每张结果记录方案与分区版本，使八面图和局部修改可追溯、可回退。

### P1：优先做确定性的多材质主体

- 对 STEP/STP、3DM、GLB 等可得到网格的模型，优先在 Blender 中按分区赋予 PBR 材质并真渲染主体；材料库映射到 base color、roughness、metallic、normal/bump 与实际纹理尺度。胶皮、塑料的细纹和包胶分界由材料与几何确定，灯光不随视角改变材料身份。
- 输出同机位的彩色材质底图、alpha、深度、法线、对象 ID 与材料 ID。AI 可用于背景、氛围或用户指定局部的审美探索，但不把“提示词说前壳塑料、握持区橡胶”视为材质分区保证。
- 当前 3D 预览只近似颜色/反射，正式结果要注明“确定性真渲染”或“AI 实验候选”，避免把预览当成最终表面效果。透明件、文字、刻度、认证标识继续走确定性路径。

### P2：选区局部渲染与千问接入

- 复用现有候选底图版本链、同机位 object ID 掩膜、ROI 裁剪及掩膜外像素保持不变的合成流程。多选部件可合并掩膜，但每个部位仍带自己的 CMF，不能把“橡胶+塑料”合成一段含糊提示词一次重绘。
- 局部修改时先确定底图来源、目标部位及当前视角；显示红色/半透明遮罩供确认。掩膜扩张与羽化按像素尺度和部件大小设置；材料边界不得跨到相邻部件。边界、贴花和透明件可走确定性后处理。
- 千问可作为美感探索或局部候选引擎：每机位以目标视角结构图或确定性材质底图为首要输入，明确某一部位的材质说明；同方案主视图可辅助产品身份，但不能替代该视角掩膜。现有 Qwen 整机路径未接入部件方案/掩膜，需单独开发并与 SDXL 局部流程区分，不承诺提示词单独实现精确分区。
- 如果纯图片输入没有 3D 模型，提供当前图片上的画笔/多边形选区和一次性局部改材；只保证该图片选区，不声称能由单张图推断背面和八面材料归属。

## 4. 预计修改位置

| 位置 | 工作内容 |
|---|---|
| `web/app.js`、`web/index.html`、`web/styles.css` | 部位列表、模型/白模选区、CMF 方案 A/B、分区预览、整机/局部两种清楚的操作入口。 |
| `web/server.py` | 方案持久化与模型指纹校验、跨视角映射、掩膜校验、任务元数据和各引擎能力限制。 |
| `config/cmf_presets.json` | 复用现有材料库；按真实样本补 PBR 贴图路径、物理尺度和材质包兼容信息，不复制第二份冲突列表。 |
| `scripts/` 中的 Blender/pass 流程 | 按网格/材料 ID 确定性赋材；按视角输出材质底图及掩膜，并保持相机一致。 |
| `web/selftest.py` 与 Windows 实机记录 | 方案读写、模型更新失效、多视角一致性、局部边界/未选区像素不变及 8GB 显存验证。 |

## 5. 验收标准与分期

1. **P0 易用性**：10 个以内常见部位能在 UI 点选、命名、选材、存方案、重新打开恢复；未分配部位有明确默认值；模型变化时提示重新映射。
2. **P1 材质准确**：同一模型前壳 ABS、握持区 TPE，在正面/侧面/双 3/4 至少四机位保持相同颜色、纹理尺度与边界；不出现橡胶跑到前壳。先做确定性主体基线，再评估 AI 美化是否破坏它。
3. **P2 局部安全**：选握持区改胶皮时，未选区与底图逐像素一致；掩膜不得为空或错位；可回退上一版。用小/中/大部件和至少两组相邻异材质边界测串色、羽化、孔位与工艺纹理。
4. **Windows 8GB 实测**：实际材质包先验格式与贴图尺寸，再分别跑单机位、四机位、八面候选；记录显存峰值、耗时、失败率和截图。未通过前不开放“大批量一键多部位 AI 精确渲染”的默认承诺。

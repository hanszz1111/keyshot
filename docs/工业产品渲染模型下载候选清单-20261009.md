# 工业产品渲染：训练模型与下载候选清单

> 检索日期：2026-10-09。本文只收录**作者/维护者的模型页或权重入口**，不镜像权重、不代表已安装或已通过本项目测试。设备目标：RTX 4060 Ti 8GB。使用前以模型页最新文件、依赖及许可为准。

## 先看结论

本项目要的是“同一件产品的八个视角、结构线及多部位 CMF 不乱”。因此先试**与现有 Qwen-Image-2.1 兼容的结构约束模型**，再试材质/相机 LoRA；“产品摄影”风格 LoRA 只解决视觉气质，**不能保证 CAD 尺寸或八面一致性**。现有 Windows 端已把 Qwen 2.1 文本编码器改为 INT8（见过程文档 v3.37），不要依据旧方案擅自改回 W4A8。以下新模型都仍是候选，不改变当前生产配置。

## 8GB 电脑的实际试验顺序

1. **先不下载新模型**：核对 `F:\AI-Renderer\experiments\Qwen21` 的 ComfyUI 版本、现有主模型/文本编码器/控制节点和空闲磁盘。给现有一个难 SKU 的正面、左右 3/4、俯视、仰视固定机位，并导出每面的深度/边缘/PBR。先有结构基线，再比较新权重。
2. **A1 单独测试**：仅下载 Comfy-Org 的 Qwen 2.1 Union INT8 model patch 到实验实例对应的 `models/model_patches`；先在独立工作流检查节点能否加载，单张 640/768 图测峰值显存、OOM、耗时。可参考 [Alibaba 原始模型说明](https://huggingface.co/alibaba-pai/Qwen-Image-2.1-Fun-Controlnet-Union)及[社区 ComfyUI 适配器](https://github.com/T8mars/Comfyui-Qwen-Image-2.1-Fun-Controlnet-Union-T8)，但**先审源码、确认版本**，不要让插件自动更新正式实例。若 8GB OOM，停止本地路线，可考虑按需 API/远程 GPU；不强行降低结构输入质量。
3. **B2 只在现有 SDXL 稳定链路需要时补**：先查已下载的 Depth/Canny 型号，避免重复文件。分别测试而非一次装两个，并和现有链路对照。
4. **A2/B1/C 类为独立模型家族**：不复制 LoRA 到当前 Qwen 2.1 文件夹“碰运气”。若确定需要多视角推断或材质迁移，再单独规划底模、显存和维护成本。只有 PBR 基底+当前 Qwen 无法解决的具体失败案例，才值得开启新的引擎项目。

每个候选做同 SKU、同机位、同种子两臂对照，记录结构（孔、分模线、部件数）、相机角度、跨视角 CMF、背景、耗时、显存；**任何单张更漂亮但八面换形/换色的候选都不晋级**。原始权重、测试图和私有素材留在 Windows 本机，Git 只登记来源、版本/哈希、许可、参数和脱敏结论。下载前对文件页再核验名称、体积和 SHA-256；不要执行模型页附带的未知脚本。

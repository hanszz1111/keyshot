# 设计语言统一与高品质案例验收

更新：2026-10-06。本文件区分**已证实的链路问题**与**尚未验证的画质推测**。公开仓库没有真实产品输出图；本轮不能凭代码或任务状态给图片打“优秀”分。

## 为什么目前优秀案例少

1. **缺少可复核的画质样本**：`AI/QWEN21-本地部署实测.md` §9 记录 18 张八面任务全部完成，并给出耗时，但明确写明**未逐机位人工核对材质/产品身份**。输出位于 Windows 本机 `outputs/`，按项目约定不入公开仓库。因此目前能证实“跑通”，不能统计“优秀率”。
2. **设计语言曾可能自相矛盾**：网页把当前背景与手动灯光拼进 AI 提示词，服务端又追加设计预设。选“户外耐用”同时选“纯白主图”之类组合会形成相反指令；千问的通用结构提示还固定要求无纹理影棚背景。多视角分别生成时，这会放大背景、反射与情绪不一致的风险。这是代码可确认的机制问题，**不是已测出的画质缺陷比例**。
3. **结构准确与视觉吸引力尚无共同验收口径**：当前自动检查主要核对模型/场景版本、文件、尺寸和缓存完整性。它不能自动判定孔位、分模线、材料边界是否准确，更不能判定工业设计美感。35 步与 50 步的 Windows 记录只证明 50 步更慢约 36%，没有同种子盲评证明更好。
4. **本地 8GB 条件有取舍**：已有千问八面实测使用 896 像素预算；提高步数、尺寸或叠加参考图会增加耗时与显存压力。更高参数不自动等于更好的外观案例。真实材质包贴图/UV 烘焙仍未完整接入，当前 PBR 保形底图只覆盖基础颜色、金属度、粗糙度和部分透明度。

## 本轮已改

- 每套设计预设指定一个匹配的背景和界面灯光。选中后相关手动控件暂锁，避免用户看到的方案与出图提示词不一致；取消预设后恢复手动选择。
- 选设计预设时，前端不再向稳定模式和千问模式重复拼入另一套通用背景/灯光句子；服务端仍负责统一追加设计预设及负面约束。千问的固定结构约束不再强制“无纹理影棚”或“studio lighting”，以免与户外/工艺特写预设矛盾。
- 若同时上传参考图，选定设计预设时只借用其配色，不让 IPAdapter 或参考图的背景/影调覆盖整组设计语言；取消预设后恢复原参考图强度行为。界面预检会说明本次实际采用哪一种方式。
- 新任务记录设计预设签名。出图时若预设内容或共用负面词已经变化，后端要求重新创建整组任务，而不是让前后机位使用不同版本。旧任务无签名仍按旧行为处理，不能追溯保证一致。
- **边界**：保形底图仍使用 Blender 固定检查光照，选设计预设只让底图背景色对齐；它是形状与 CMF 核对基线，不是最终设计灯光成图。千问仍可能改形，选预设不能替代逐张验收。

## Windows 高品质案例筛选流程（待执行）

1. 选 1 个有塑料、包胶、金属交界且有不对称孔位的真实模型；固定 8 个机位、同一 CMF 方案、种子 43、896 预算、35 步。先生成八张保形底图，核对几何与材质归属。此步不过，停止 AI 对照并修 CAD/CMF。
2. 只选 **1 套**与产品定位相符的设计预设，每机位先出 1 张；不要混用“户外/实验室/极简”去拼一组。对八张分别记录：结构准确、部位材质、光照/背景统一、质感可信、视觉主次，各项 0–2 分，并记录具体错误位置。结构或材质项有 0 分，该图直接不入优秀案例。
3. 八张中若有失败，不要只重抽失败视角后混入旧系列；保留整组编号与原参数，记录“失败机位/原因”，更改方案后重新生成一组。否则无法知道改进来自预设、种子还是偶然采样。
4. 至少重复 2 个种子、再换 1 件不同产品；对比同条件下每组的“8/8 结构合格率”和“8/8 风格一致率”。只有连续通过的整组才进入本机精选案例。单张漂亮但七张不一致，标为“概念探索”，不算八面成套案例。
5. 样图保存在 Windows 本机，另存匿名评分表、参数和任务编号；公开仓库只提交脱敏的评分汇总。若要公开原图，先确认产品资产与参考图可公开。

## 下一步优先级

- P0：完成上面的真实图评分；没有样本前，不宣称优秀率提升。
- P1：若保形图通过但 AI 图改孔/串色，研究按前景轮廓、孔位和材质区域做输出后验收，必要时直接采用保形图主体，仅做局部/背景增强。
- P2：若几何准确但“高级感”不足，再按同种子比较预设光照、材质微纹理与构图，不先盲目提高步数。

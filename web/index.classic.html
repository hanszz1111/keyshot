参数卡

L0 / L1 · 渲染参数卡编辑与落盘 阶段 P0 文档 —
参数卡是本方案的核心接口契约（过程文档 ADR-003 / 5.4）。三种输入方式最终都收敛到这里：自然语言 → 参数卡 → 人工复核 → 落盘。提示词由参数卡程序化拼装，不手写。

asset产品与机位

白模路径、类目、SKU、要出的机位。机位用球坐标预设，一套预设跨模型复用。

material材质

用参数（roughness / metallic）而非形容词 —— 参数可映射到引擎，形容词只能映射到 AI 的模糊理解（ADR-003）。

主体 body
附属件 trim 可选
透明件 window 可选 · 注意风险 #2
AI 对透射材质能力不足（边界声明 7.5）。带透明件的产品建议：透明区域用 KeyShot 真渲染后合成，不要把透明件交给 AI 硬刚。

lighting光照

首选在 KeyShot 里换 HDR 环境真三维重渲，比让 AI 猜光照可靠（ADR-009）。IC-Light 只用于"手里只有一张现成图"的场景。

camera相机 · background背景

相机参数必须与 L2 出 pass 时完全一致，否则 Pass 与成图不对齐、ControlNet 失效（ADR-009 / 风险 #7）。

reference参考图仿照

三档强度必须显式选择（ADR-005）。混为一谈会导致大量无效试错 —— 三档对应的权重差异巨大。

FLUX Redux 已知行为：高权重时完全忽略提示词，只复刻参考图 → 必须配 AdvancedRefluxControl 用 downsampling_factor 把两个力掰开。
已知限制：只接受正方形输入，所以有 center crop / keep aspect ratio / autocrop with mask 三种裁切。

为什么必须这样写

          

            

              
① prompt 里禁止写形状词

              

                形状由 ControlNet 用 depth/normal 锁死。写形状词会与 ControlNet 信号冲突，且是 AI 最不可控的输入（ADR-002）。

                自检：如果你发现要写很长的形状描述才能出对图，说明 depth 权重没调好，回去调 9.3 第 1 步。
              

            

            

              
② 负向词必须排除文字

              

                负向词里显式包含 text / numbers / logo / markings，AI 就不会去"猜"丝印内容，留下干净表面供后期回贴（ADR-002）。

                这是把「丝印错乱」这个 🔴 高风险从 AI 侧摘掉的关键动作。
              

            

            

              
③ 调参顺序不能平行

              

                只开 Depth（0.60 起）→ 加 Normal（0.35 起）→ 加参考图（低权重）→ 最后才调 prompt → 打光单独一轮。

                Normal 权重超过 0.5 要警惕，画面会发"塑料感"和"死灰"。
